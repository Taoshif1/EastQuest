## Deployment boundary

Hosting configuration is separate from game logic: the same Next.js build runs
locally and on Vercel. No repository secrets or backend setup are needed for local
mode. Preview and production use one dedicated taoshifs-projects/eastquest project.
The Git integration deploys feature pushes as previews and main as production.
Do not create a second EastQuest project or deploy into a portfolio project.

Progress is browser- and origin-specific. Preview, production and localhost each
have separate local saves. Do not mistake that for lost server progress.
Keep the student-built / unofficial disclaimer and closed-playtest labeling.

## GitHub tooling

The gh command is not installed. Existing Git credentials authorize pushes and
GitHub REST operations; the connected GitHub app is read-only. Repository metadata
was configured through GitHub REST without saving or printing credentials.

For a teammate who wants the CLI on Windows:
```powershell
winget install --id GitHub.cli -e
# Open a fresh terminal
gh auth login --hostname github.com --web
gh auth status
gh repo view Taoshif1/EastQuest
```
