# Playable case system

The Lost Campus File is a fictional, data-driven case. It starts in the game
when the player investigates a loose fragment near the Main Outer Gate. The
case then uses proximity interactions at the Library, ICS Computer Lab, Career
Counseling Center Lobby, and Medical Center. These are gameplay markers and do
not claim that the fictional evidence exists at those locations.

Case progress is persisted with the existing local save. Clues are unique,
hints and pinning are persisted, optional evidence can be skipped, and the
completion reward is idempotent. The ordinary five-key quest remains separate.
