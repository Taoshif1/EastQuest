# Case mini-games

Case mini-games return `SUCCESS`, `FAILED`, or `CANCELLED` metadata to the
case controller. The current reusable configurations include sequence/pattern,
evidence ordering, and timing/reflex evaluation. The Lost Campus File uses
pattern and evidence ordering; the timing configuration is reserved for the
optional Campus Reflex activity.

Patterns and evidence orders are configuration-driven and deterministic. A
specialty is never required to solve a case.
