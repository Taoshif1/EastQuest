# V0.3B Campus Life

Campus activities are content-driven records in `src/game/activities/data.ts`.
Each record declares a broad domain, optional specialty, reward, and a reusable
runner type (`choice`, `timing`, `penalty`, or `reaction`). Specialty is a
recommendation only; no activity blocks a player without a matching profile
focus.

## Player loop

`/activities` is the drop-in hub. Choice activities teach a short campus
skill, while the sports arcade provides a timing meter, a futsal penalty
corner-picker, and a reaction test. A successful first clear awards XP and a
stamp. Replays update the best score without duplicating XP.

Achievements and NPC rumors are intentionally fictional game content. Hidden
stories are surfaced in the activity hub and notebook collection, and the UI
reminds players to respect closed areas and ask staff before exploring.

## Save migration

V0.3B keeps the V0.3A save envelope (`version: 1`) so existing local profiles
remain readable. `LocalGameRepository.load` fills missing `activities`,
`achievements`, `stamps`, and `discoveredRumors` fields with safe defaults;
unknown or malformed legacy saves still fail closed. New saves include these
fields from `newGame`.

## V0.3B2 campus-life slice

Campus-life content is data-driven in `src/game/campus-life/data.ts`. The
Phaser scene renders 16 non-blocking interaction markers and six fictional
NPCs across exploration floors, while the existing interaction bridge opens
the same UI modal architecture used by quests and cases. Eight hidden
discoveries award one-time set stamps and XP, and NPC conversations can start
five reusable multi-step side quests (including the branching Shared Campus
route). Progress, NPC contacts, notifications, and discovery stamps migrate
with the V0.3B save envelope.

`/sports` is a focused view over the existing activity runner. Cricket timing,
penalty, and reaction activities use the same score, medal/stamp, and first
clear reward rules. `/activities` also exposes a deterministic date-keyed
daily challenge with an idempotent once-per-date reward. `/quests`, collection,
and profile views expose side-quest state, hidden sets, contacts, explorer
rank, and domain progress. All content is fictional and public-space aware;
closed areas remain out of bounds.
