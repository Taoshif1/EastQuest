# Campus source register

## Evidence meanings

- VERIFIED: the cited public directory explicitly states the service/block/floor; it does not verify game coordinates or current access.
- FIELD_OBSERVED: supplied arrival observations attributed to Taoshif; measurements and reinspection are pending.
- APPROXIMATED: rectified pixel geometry, marker offsets, furnishings, door widths and lift service assumptions.
- FLOORPLAN_REFERENCE: a supplied architectural drawing; HIGH source confidence is not a claim of centimetre-accurate tracing.
